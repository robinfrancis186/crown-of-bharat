# Economy building levels

Levels 2–15 use original editable solid geometry and two shared vertex-color materials. Level 1 continues to use each existing base GLB and PNG. The placement grid never expands: the four ordinary buildings fit 3×3 cells and Gem Garden fits 2×2. Gold trim accompanies new working structures; no upgrade is only a recolor or banner.

Run `Blender -b --factory-startup --python tools/build-levels-economy.py`. Source collections are named `farm_02` through `gem_mine_15`; only `farm_15` starts visible. Source preserves individual functional component groups, while exports merge them to two material batches. Mobile export ceiling: 20,000 triangles. Runtime portraits are transparent 512×512 CPU Cycles renders.
